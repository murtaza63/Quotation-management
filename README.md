# Quotation Management System

A full-stack quotation management system 
built for demolition and construction companies.

## Tech Stack
- Frontend: React.js
- Backend: FastAPI (Python)
- Database: PostgreSQL

## Features
- Create and manage client quotations
- Track project costs and pricing
- Generate quotation documents
- Client and project management

## Setup

### Backend

cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload


### Frontend

cd frontend
npm install
npm start


## About
